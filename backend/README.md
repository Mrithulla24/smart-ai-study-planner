# Smart AI Study Planner - Backend

This folder contains the Flask REST API, database connection, and AI recommendation modules for the Smart AI Study Planner.

## Technologies
- Python
- Flask
- MySQL
- Pandas, NumPy, and scikit-learn

## Setup
Install the dependencies listed in requirements.txt.
Configure your database credentials using environment variables in a local .env file.

Never commit passwords or secret credentials to GitHub.
